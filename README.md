# Calculadora de Juros Compostos

## Objetivo
Simular a evolução de um investimento com aportes mensais e juros compostos.

## Funcionalidades
- Recebe valor inicial, aporte mensal, taxa ao mês e prazo.
- Mostra o total investido, os juros ganhos e o saldo final.

## Tecnologias
- Python 3

## Como executar
```bash
git clone https://github.com/Matheusewert/Calculadora-juros-compostos.git
cd Calculadora-juros-compostos
python calculadora.py
```

## Exemplo
Entradas: R$ 1.000 inicial, R$ 300 por mês, 1% ao mês, 12 meses.
```
Total investido: R$ 4600.00
Saldo final: R$ 4931.58
Juros ganhos: R$ 331.58
```
